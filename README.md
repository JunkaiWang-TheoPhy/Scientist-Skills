## Introduction

Hard problems rarely need only one kind of intelligence. One method reframes a paradigm, another tests the load-bearing claim, and a third rebuilds kinematics from observable transitions. Pauli adds adversarial review, calibrated judgment, and minimal constructive repair. Others invent concepts, construct robust models, translate descriptions, remove inherited scaffolding, complete consistency, close analytic gates, deform, enumerate, or redesign representation.

`Scientist-Skills` puts thirteen such methods on one map. Every name denotes an evidence-grounded methodological collective, never a simulation of a person. Each standalone repository carries an operational kernel and explicit identity boundaries; the distill-scientist profiles additionally carry claim, lineage, counterevidence, and behavioral-evaluation ledgers.

## Method constellation

```text
reframe paradigms ── test load-bearing claims ── reconstruct observable kinematics
invent concepts ── build models ── translate ── remove scaffolding ── complete consistency
close analysis ── review and judge ── protect and deform ── enumerate ── redesign representation
```
