## Introduction

Hard problems rarely need only one kind of intelligence. One method compresses a theory into its smallest robust model; another invents a primitive the old language cannot express; others translate between descriptions, remove inherited scaffolding, complete consistency, close analytic gates, deform, enumerate, or redesign representation.

`Scientist-Skills` puts nine such methods on one map. Every name denotes an evidence-grounded methodological collective, never a simulation of a person. Each standalone repository carries an operational kernel, public-source ledger, intellectual lineage, counterevidence, and behavioral evaluation.

## Method constellation

```text
invent concepts ── build models ── translate descriptions ── remove scaffolding
       └── complete consistency ── close analysis ── deform ── enumerate ── represent
```

| Skill | Method style |
| --- | --- |
| [`Kitaev Skill`](https://github.com/JunkaiWang-TheoPhy/Kitaev-Skill) | Build the smallest model in which the desired phenomenon has nowhere to go. |
| [`Wen Skill`](https://github.com/JunkaiWang-TheoPhy/Wen-Skill) | Invent the primitive that makes hidden organization speakable before measuring it. |
| [`Juan Skill`](https://github.com/JunkaiWang-TheoPhy/Juan-Skill) | Make two descriptions earn their equivalence through a shared observable dictionary. |
| [`Nima Skill`](https://github.com/JunkaiWang-TheoPhy/Nima-Skill) | Strip away inherited scaffolding until observables arise from the smallest generating structure. |
| [`Yang Skill`](https://github.com/JunkaiWang-TheoPhy/Yang-Skill) | Find where a trusted principle breaks under localization and add only what consistency demands. |
| [`Yau Skill`](https://github.com/JunkaiWang-TheoPhy/Yau-Skill) | Turn a global theorem into one seed equation, then close every analytic gate. |
| [`Seiberg Skill`](https://github.com/JunkaiWang-TheoPhy/Seiberg-Skill) | Reconstruct inaccessible dynamics from protected data, controlled deformations, and reverse consistency. |
| [`Nikita Skill`](https://github.com/JunkaiWang-TheoPhy/Nikita-Skill) | Deform a continuous problem until it localizes into discrete data and a master generating object. |
| [`Siegel Skill`](https://github.com/JunkaiWang-TheoPhy/Siegel-Skill) | Change the representation until symmetries, constraints, and calculational leverage become manifest. |
