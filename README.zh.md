## 引言

困难问题很少只需要一种聪明。有人把理论压缩成最小而鲁棒的模型，有人发明旧语言尚不存在的原语，有人建立两种描述之间的字典，也有人通过变形、枚举、表示重构或分析闭合把不可解问题变得可控。

`Scientist-Skills` 把九套方法放在同一张地图上。每个名称都是公共证据支持的方法群像，不是对具体人物的模拟。独立仓库保留方法核、来源台账、学术脉络、反证与行为评测。

## 方法星图

```text
发明概念 ── 构造模型 ── 建立字典 ── 删除中介 ── 补全一致性
    └── 分析闭合 ── 受控变形 ── 精确枚举 ── 重构表示
```

| Skill | 方法风格 |
| --- | --- |
| [`Kitaev Skill`](https://github.com/JunkaiWang-TheoPhy/Kitaev-Skill) | 构造最小模型，让目标现象由结构保护而无处可逃。 |
| [`Wen Skill`](https://github.com/JunkaiWang-TheoPhy/Wen-Skill) | 先发明能说出隐藏组织的原语，再谈如何测量它。 |
| [`Juan Skill`](https://github.com/JunkaiWang-TheoPhy/Juan-Skill) | 让两种描述通过共同的 observable 字典赢得对应关系。 |
| [`Nima Skill`](https://github.com/JunkaiWang-TheoPhy/Nima-Skill) | 剥去继承的脚手架，直到 observable 从最小生成结构中直接涌现。 |
| [`Yang Skill`](https://github.com/JunkaiWang-TheoPhy/Yang-Skill) | 找到可信原则在局域化时破裂的位置，只加入一致性真正要求的结构。 |
| [`Yau Skill`](https://github.com/JunkaiWang-TheoPhy/Yau-Skill) | 把整体定理压成一个种子方程，再逐门关闭所有分析门槛。 |
| [`Seiberg Skill`](https://github.com/JunkaiWang-TheoPhy/Seiberg-Skill) | 从保护数据、受控变形与反向一致性中重建不可直接求解的动力学。 |
| [`Nikita Skill`](https://github.com/JunkaiWang-TheoPhy/Nikita-Skill) | 把连续问题变形到局域化为离散数据与母生成对象。 |
| [`Siegel Skill`](https://github.com/JunkaiWang-TheoPhy/Siegel-Skill) | 改变表示，直到对称性、约束与计算杠杆全部显式。 |
